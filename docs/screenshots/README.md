# Screenshot capture notes

Captured on 18 October 2026 using the published RepoPilot v0.1.0 Apple Silicon binary installed through Homebrew.

- `welcome.jpg`: a real interactive Zsh PTY session running `repopilot`, followed by `git status --short --branch` in a clean clone on `main`.
- `workflow-guide.jpg`: the same session after clearing the terminal and running `repopilot guide "undo last commit"`. The guide commands were displayed, not executed.

The PTY's actual ANSI output was rendered with xterm.js 6.0.0 and captured as browser screenshots. The frame, title and footer belong to the capture presentation. Colors, font, wrapping and shell configuration may differ in another terminal. A disposable home directory and project clone kept personal paths and configuration out of the captures; no AI request was made.
