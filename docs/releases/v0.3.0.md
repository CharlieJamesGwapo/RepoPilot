# RepoPilot v0.3.0 — security, token controls and local coding models

RepoPilot v0.3.0 brings security hardening, explicit response budgets and optional local coding-model setup. Download binaries for Apple Silicon macOS, Intel macOS, x86-64 Linux GNU and x86-64 Windows below.

Install on macOS: `brew install charliejamesgwapo/tap/repopilot`. Existing users: `brew update && brew upgrade charliejamesgwapo/tap/repopilot`.

See the [installation guide](https://github.com/CharlieJamesGwapo/RepoPilot/blob/v0.3.0/docs/installation.md) for reviewed installers and checksum verification.

## Security and reliability

Provider metadata cannot include terminal control characters that could spoof consent. Bash prompt hooks ending in semicolons or comments continue to run. Installer requests have bounded timeouts and failed-download tests preserve existing files. Separate model configuration refuses aliases of the saved user config.

Security reporting and repository scanning are enabled. CI uses pinned action commits, dependency audits and native installer tests. Shells, installed executables and local model runtimes retain their normal privileges; RepoPilot is not a sandbox. Release binaries remain unsigned and unnotarized.

## Explicit token controls

```sh
repopilot chat --max-output-tokens 256
# In chat: /budget 256, /budget off, /usage
```

Compatible HTTP providers receive an optional response-token ceiling. JSON output preserves reported usage and truncation metadata, including responses with no visible text at a low limit. Setup probes respect the session budget too. Missing usage remains unknown; no prompt caching, universal cost limits or unmeasured savings percentages are advertised.

## Optional open-weight coding models

```sh
repopilot models list
repopilot models setup balanced --output ./local-coder.toml
```

The catalog includes Apache-2.0 Qwen checkpoints with explicit manual download instructions and local-only configuration. General coding models can assist frontend, backend and DevOps work; these are not separate specialist fine-tunes. Catalog/setup never downloads weights, starts services or overwrites saved configuration.

Your native shell, installed Claude/Codex tools, offline project diagnostics and ten built-in workflow skills remain available.
