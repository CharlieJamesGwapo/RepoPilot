RepoPilot's first release: a free, open-source shell workspace with local project diagnostics, offline workflow guides, and separate optional AI chat.

### Download and install

Download the archive for your machine below, or follow the [installation guide](https://github.com/CharlieJamesGwapo/RepoPilot/blob/v0.1.0/docs/installation.md). No Rust toolchain is needed for the binaries.

**macOS / Linux** — download the installer, review it, then run it:

```sh
curl -fL https://github.com/CharlieJamesGwapo/RepoPilot/releases/download/v0.1.0/install.sh -o install-repopilot.sh
sh install-repopilot.sh
```

Default destination: `~/.local/bin`. Add that directory to PATH if needed. `REPOPILOT_INSTALL_DIR` selects a different destination; `REPOPILOT_VERSION` selects a release tag.

**Windows x64** — in PowerShell, download and review the installer, then run it:

```powershell
Invoke-WebRequest https://github.com/CharlieJamesGwapo/RepoPilot/releases/download/v0.1.0/install.ps1 -OutFile install-repopilot.ps1
& .\install-repopilot.ps1
```

Default destination: `%LOCALAPPDATA%\RepoPilot\bin`. Add it to your user PATH and open a new terminal. If your execution policy blocks local scripts, use the manual installation instructions instead.

The installers verify archive SHA-256 and binary version before installing. Archive and installer checksum assets are included. Binaries are unsigned and macOS builds are not notarized. Linux x64 uses the Ubuntu 22.04/glibc baseline; unsupported architectures can build from source.

### Try it

```sh
repopilot
repopilot guide "undo last commit"
repopilot doctor .
repopilot report . --format markdown
repopilot chat
```

Bare `repopilot` opens your real shell. Interactive Zsh/Bash get the branded folder/Git prompt; other shells retain their normal prompt. Run installed commands such as `claude`, `codex`, and Git normally. Vendor tools manage their own authentication, network use, and billing. Local-model chat requires a separately installed compatible runtime/model; neither is bundled.

See the [user guide](https://github.com/CharlieJamesGwapo/RepoPilot/blob/v0.1.0/docs/user-guide.md) and [changelog](https://github.com/CharlieJamesGwapo/RepoPilot/blob/v0.1.0/CHANGELOG.md).
