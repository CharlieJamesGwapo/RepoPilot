# RepoPilot v0.2.0 — built-in developer and UI/UX skills

RepoPilot now includes ten offline, self-contained skill workflows. Browse them, read their instructions, and explicitly export one into a project for portable use, Codex, or Claude.

```sh
brew install charliejamesgwapo/tap/repopilot
# Existing installations:
brew update && brew upgrade charliejamesgwapo/tap/repopilot

repopilot skills list
repopilot skills show debugging
repopilot skills export debugging --path ./my-project --target codex
repopilot skills export ui-review --path ./my-project --target claude
```

Development: planning, test-driven-development, debugging, code-review, verification. These are standalone MIT-licensed Superpowers adaptations, with attribution; they are not the complete upstream plugin.

UI/UX: original RepoPilot guidance for layout, typography, responsive design, accessibility, and UI review.

Exports include SKILL.md, LICENSE.txt and NOTICE.md. They refuse existing destinations, support --dry-run and --json, and modify only the explicitly selected project. Exporting starts no agent, grants no permissions, and changes no global agent configuration. Your real shell, installed Claude/Codex tools, and separate local AI chat continue to work normally.

Download the matching archive below for Apple Silicon macOS, Intel macOS, x86-64 Linux GNU, or x86-64 Windows. Verify its .sha256 file. Reviewed installers are included as assets and default to v0.2.0; binaries are unsigned and macOS builds are not notarized.
