# UI layout

## Purpose

Arrange an interface around user tasks, clear hierarchy, and resilient content.

## Workflow

1. Identify the primary user task, essential content, and the action that completes it.
2. Review existing design conventions and reuse the established component system.
3. Group related content and order it according to task flow and reading sequence.
4. Choose a small spacing scale and apply it consistently to alignment and grouping.
5. Use size, position, and contrast to distinguish primary actions from supporting detail.
6. Design realistic loading, empty, error, and success states alongside the main screen.
7. Test with long labels, missing optional content, and dense real-world data.
8. Keep visual order compatible with document order and keyboard navigation.
9. Check narrow and wide layouts without hiding essential actions or information.
10. Compare the rendered result with the task and remove decoration that obstructs it.

## Deliverable

A coherent layout with documented hierarchy, responsive behavior, and state coverage.

## Evidence

A user can locate the primary task and complete it across tested content and viewport conditions.

Record the relevant inputs, observed results, and limits of the check.
Do not substitute confidence, a screenshot alone, or a prior run for current evidence.
