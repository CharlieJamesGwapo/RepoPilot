# Practical typography

## Purpose

Create readable text hierarchy using existing fonts, measured spacing, and resilient wrapping.

## Workflow

1. Identify reading contexts: headings, body copy, controls, captions, and code.
2. Use the project font stack or system fonts; do not download unapproved font assets.
3. Define a restrained type scale with clear roles rather than many unrelated sizes.
4. Use weight and spacing deliberately while preserving readable body text.
5. Choose line length and line height appropriate to sustained reading and narrow screens.
6. Check long words, URLs, localized labels, and multiline headings for overflow.
7. Preserve text selection and zoom; avoid images of text for ordinary interface copy.
8. Test fallback fonts so missing assets do not break hierarchy or alignment.
9. Inspect contrast and interactive labels in normal, disabled, error, and selected states.
10. Review at enlarged text settings and adjust containers instead of clipping content.

## Deliverable

A small type specification and rendered examples covering text roles and edge cases.

## Evidence

Text remains legible and meaningful when fonts fall back, strings grow, and users enlarge content.

Record the relevant inputs, observed results, and limits of the check.
Do not substitute confidence, a screenshot alone, or a prior run for current evidence.
